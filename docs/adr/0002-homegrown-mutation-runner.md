# ADR 0002：自研突变测试 runner 而非 mutmut

状态：accepted（2026-09-25 定）

## 背景

用户质疑「测试到底准不准」。选型评估 mutmut3：与本项目的
pytest-asyncio/conftest 隔离体系兼容性差，且全量跑法（不按文件映射
窄测试集）在 1300+ 用例的仓库上不可行。

## 决策

自研 `scripts/mutate.py`（~370 行）：AST 定位变异点+5 算子（比较反转/
and·or/True·False/if 恒真恒假/常数±1）+ **TARGET_TESTS 文件→窄测试集
映射**（每变异只跑最小充分集）+ 存活复验 + git 原子恢复 + 分段参数。

## 后果

- 正面：两天扫完 41 文件 2589 变异；挖出 11 个真 bug 与 ~110 处否定
  路径盲区；runner 自身 4 个基建坑也被实战修掉（多行假杀/pyc 陈旧/
  并发互冲/映射丢失）
- 代价：自维护（无社区算子更新）；映射是手工债——新文件必须登记
  （宪法「测试同步纪律」第 1 条）
- 关键教训（对后来者）：**突变 runner 的可信度本身需要审计**——
  映射完备性、字节码缓存、并发 checkout 都是失真源
