# ADR 0003：文档双语策略——英文主文件 + 中文镜像

状态：accepted（2026-09-28，项目所有者拍板：双语、面向多人贡献）

## 决策

- `README.md` 为**英文主文件**（GitHub 默认受众），`README.zh-CN.md`
  为中文镜像，顶部互链
- `docs/` 主题文档（ARCHITECTURE/CONFIG/PROTOCOL/…）现阶段中文为主
  （维护成本），英文版随文档站建设逐步补
- 代码注释与 commit message：中英均可，说明 why 即可
- CHANGELOG 中文为主（项目工作语言），大版本条目可加一行英文摘要

## 后果

- 正面：国际受众第一屏可读；中文社区有完整镜像
- 代价：README 双份同步是长期债——**改 README 必须同改两份**（写入
  PR 自查项）；文档站建成后考虑单源双构建
