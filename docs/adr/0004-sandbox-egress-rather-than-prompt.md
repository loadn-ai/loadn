# ADR 0004：安全靠确定性代码，不靠提示词

状态：accepted（项目奠基原则，W0-W6 安全栈的总纲）

## 决策

所有安全红线是**确定性代码**（bwrap 挂载矩阵/出口代理/权限策略引擎/
哈希链审计），不依赖模型听话：提示词里写「不要外发凭证」不是防线，
出口代理白名单才是。原则表述：**策略在模型之外**。

配套纪律：新能力默认 fail-closed（探测不到组件降级到更严一档并审计）；
宪法红线不可配置（审计链零开关/确认码门/信任门/SSRF 私网段）；凭证
不落日志（redact 总闸）。

## 后果

- 正面：模型被越狱/提示注入不改变安全边界；安全行为可测试（41 文件
  突变验证里安全批占 19 个）——提示词约束无法写对赌测试
- 代价：防御纵深带来运维复杂度（三态档位/降级路径），故 v0.6.5 把
  全部机制显式配置化并写参考文档（docs/CONFIG.md）
- 关联：docs/ATTACK_SURFACE.md（攻击面清单）是这个原则的反面盘点
